# Country Data Loop Analysis

A small Python mini-project for practicing loops and iteration with Pandas and NumPy.

## What I Practiced

- `while` loops
- `for` loops
- `enumerate()`
- Dictionary `.items()`
- NumPy array iteration
- `np.nditer()`
- Pandas `iterrows()`
- `apply()`

## Dataset

The dataset contains 8 countries with:

- Country
- Capital
- Population (millions)
- GDP per capita (USD)
- Area (million km²)

The data is manually created for learning purposes.

## Key Practice

The project compares using `iterrows()` with using `apply()` for applying a function to a DataFrame column.
